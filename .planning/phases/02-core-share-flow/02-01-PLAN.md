Existing S3Service uses URLSession + `x-amz-access-key` header for simple auth. Pre-signed URLs require SigV4 signing since the entire point is distributing a URL that works without embedding the secret key. CommonCrypto is a system framework on macOS — no SPM dependency needed.

Current S3Service interface:
```swift
struct S3Service {
    init(config: S3Config)
    func testConnection() async -> Result<[String], S3Error>
    func ping() async -> Bool
    func bucketExists() async -> Result<Bool, S3Error>
    func createBucket() async -> Result<Void, S3Error>
    func ensureBucketExists() async -> Result<Bool, S3Error>
}
```

Key design decisions:
- **Upload uses same `x-amz-access-key` auth** as existing methods — consistent with Phase 1
- **Pre-signed URL uses SigV4** — required for link sharing (secret key NOT in the URL)
- **CommonCrypto** — system framework, no external deps, maintains zero-dependency approach
- **Upload path:** `shares/{duration}/{filename}` per SHAR-07
- **Pre-signed URL expires** at the same duration selected by user
- Duration values: "1h" (3600s), "1d" (86400s), "7d" (604800s), "1m" (~2592000s), "forever" (0 = no expiry — generate URL without expiration param)

    ```swift
    import Foundation
    import CommonCrypto

    // MARK: - HMAC-SHA256

    extension Data {
        /// Compute HMAC-SHA256 of this data with the given key.
        func hmacSHA256(key: Data) -> Data {
            var mac = [UInt8](repeating: 0, count: Int(CC_SHA256_DIGEST_LENGTH))
            key.withUnsafeBytes { keyBytes in
                self.withUnsafeBytes { dataBytes in
                    CCHmac(
                        CCHmacAlgorithm(kCCHmacAlgSHA256),
                        keyBytes.baseAddress, key.count,
                        dataBytes.baseAddress, self.count,
                        &mac
                    )
                }
            }
            return Data(mac)
        }

        /// SHA-256 hash of this data.
        var sha256: Data {
            var hash = [UInt8](repeating: 0, count: Int(CC_SHA256_DIGEST_LENGTH))
            self.withUnsafeBytes { dataBytes in
                CC_SHA256(dataBytes.baseAddress, CC_LONG(self.count), &hash)
            }
            return Data(hash)
        }

        /// Hex-encoded lowercase string (e.g. for signatures).
        var hexString: String {
            map { String(format: "%02x", $0) }.joined()
        }
    }

    // MARK: - String Helpers for SigV4

    extension String {
        /// SHA-256 hash of UTF-8 encoded string, hex-encoded.
        var sha256Hex: String {
            Data(utf8).sha256.hexString
        }

        /// HMAC-SHA256 of UTF-8 encoded string with the given key (Data).
        func hmacSHA256(key: Data) -> Data {
            Data(utf8).hmacSHA256(key: key)
        }

        /// HMAC-SHA256 of UTF-8 encoded string with the given key (String).
        func hmacSHA256(key: String) -> Data {
            Data(utf8).hmacSHA256(key: Data(key.utf8))
        }

        /// URL-encode for query parameter values.
        var uriEncoded: String {
            addingPercentEncoding(withAllowedCharacters: .urlQueryAllowed) ?? self
        }
    }

    // MARK: - SigV4 Signing Key Derivation

    /// Derives the AWS SigV4 signing key.
    /// - Parameters:
    ///   - secretKey: AWS secret access key
    ///   - dateStamp: YYYYMMDD date string
    ///   - region: AWS region (e.g. "us-east-1")
    ///   - service: AWS service name (e.g. "s3")
    /// - Returns: 32-byte signing key as Data
    func sigV4SigningKey(secretKey: String, dateStamp: String, region: String, service: String) -> Data {
        let kSecret = Data("AWS4\(secretKey)".utf8)
        let kDate = dateStamp.hmacSHA256(key: kSecret)
        let kRegion = region.hmacSHA256(key: kDate)
        let kService = service.hmacSHA256(key: kRegion)
        let kSigning = "aws4_request".hmacSHA256(key: kService)
        return kSigning
    }

    /// Formats a date as YYYYMMDD for SigV4 credential scope.
    func sigV4DateStamp(from date: Date = Date()) -> String {
        let formatter = DateFormatter()
        formatter.dateFormat = "yyyyMMdd"
        formatter.timeZone = TimeZone(secondsFromGMT: 0)
        return formatter.string(from: date)
    }

    /// Formats a date as YYYYMMDD'T'HHmmss'Z' for SigV4 X-Amz-Date.
    func sigV4AmzDate(from date: Date = Date()) -> String {
        let formatter = DateFormatter()
        formatter.dateFormat = "yyyyMMdd'T'HHmmss'Z'"
        formatter.timeZone = TimeZone(secondsFromGMT: 0)
        return formatter.string(from: date)
    }
    ```

    This is pure utility code — no SPM dependency required. CommonCrypto is part of macOS SDK.

    ```swift
        // MARK: - File Upload

        /// Uploads a file to S3 under `shares/{duration}/{filename}`.
        /// Uses the same x-amz-access-key auth as existing methods.
        /// - Parameters:
        ///   - fileURL: Local file URL to upload
        ///   - duration: Duration label (1h, 1d, 7d, 1m, forever)
        ///   - progressHandler: Optional callback with fraction completed (0.0 to 1.0)
        /// - Returns: The S3 object key (path) on success
        func uploadFile(
            fileURL: URL,
            duration: String,
            progressHandler: (@Sendable (Double) -> Void)? = nil
        ) async -> Result<String, S3Error> {
            guard config.isValid else {
                return .failure(.invalidConfig("All credential fields must be non-empty"))
            }

            guard let base = baseURL else {
                return .failure(.connectionFailed("Invalid endpoint URL"))
            }

            let filename = fileURL.lastPathComponent
            let objectKey = "shares/\(duration)/\(filename)"
            let url = base.appendingPathComponent(config.bucketName).appendingPathComponent(objectKey)

            // Read file data
            guard let fileData = try? Data(contentsOf: fileURL) else {
                return .failure(.uploadFailed("Cannot read file at \(fileURL.path)"))
            }

            var request = URLRequest(url: url)
            request.httpMethod = "PUT"
            request.httpBody = fileData
            request.setValue(config.accessKey, forHTTPHeaderField: "x-amz-access-key")
            request.setValue(ISO8601DateFormatter().string(from: Date()), forHTTPHeaderField: "Date")
            request.setValue("application/octet-stream", forHTTPHeaderField: "Content-Type")
            request.setValue("\(fileData.count)", forHTTPHeaderField: "Content-Length")

            do {
                let (_, response) = try await URLSession.shared.data(for: request)
                guard let httpResponse = response as? HTTPURLResponse else {
                    return .failure(.uploadFailed("Invalid response"))
                }

                guard (200...299).contains(httpResponse.statusCode) else {
                    return .failure(.uploadFailed("HTTP \(httpResponse.statusCode)"))
                }

                // Report progress as complete
                progressHandler?(1.0)

                return .success(objectKey)
            } catch {
                return .failure(.uploadFailed(error.localizedDescription))
            }
        }
    ```

    **Step 3: Add generatePresignedURL() method to S3Service** (append before the closing brace of the struct):

    ```swift
        // MARK: - Pre-signed URL Generation (SigV4)

        /// Generates a pre-signed GET URL for an S3 object with the given duration.
        /// Uses AWS SigV4 signing via CommonCrypto.
        /// - Parameters:
        ///   - objectKey: S3 object key/path (e.g. "shares/1h/myfile.zip")
        ///   - durationSeconds: Seconds until URL expires (0 = no expiry)
        /// - Returns: Pre-signed URL string on success
        func generatePresignedURL(objectKey: String, durationSeconds: Int) -> Result<String, S3Error> {
            guard config.isValid else {
                return .failure(.invalidConfig("All credential fields must be non-empty"))
            }

            guard let base = baseURL,
                  var components = URLComponents(url: base, resolvingAgainstBaseURL: false) else {
                return .failure(.presignFailed("Invalid endpoint URL"))
            }

            // Ensure clean host without path
            components.path = "/\(config.bucketName)/\(objectKey)"

            let now = Date()
            let amzDate = sigV4AmzDate(from: now)
            let dateStamp = sigV4DateStamp(from: now)
            let region = config.region
            let service = "s3"
            let algorithm = "AWS4-HMAC-SHA256"

            guard let host = components.host else {
                return .failure(.presignFailed("Cannot extract host from endpoint URL"))
            }

            // Credential scope
            let credentialScope = "\(dateStamp)/\(region)/\(service)/aws4_request"
            let credential = "\(config.accessKey)/\(credentialScope)"

            // Query parameters for the pre-signed URL
            var queryItems: [URLQueryItem] = [
                URLQueryItem(name: "X-Amz-Algorithm", value: algorithm),
                URLQueryItem(name: "X-Amz-Credential", value: credential),
                URLQueryItem(name: "X-Amz-Date", value: amzDate),
                URLQueryItem(name: "X-Amz-Expires", value: "\(durationSeconds)"),
                URLQueryItem(name: "X-Amz-SignedHeaders", value: "host"),
            ]

            // Sort query params by name for canonical ordering
            queryItems.sort { $0.name < $1.name || ($0.name == $1.name && ($0.value ?? "") < ($1.value ?? "")) }

            // Build canonical query string
            let canonicalQueryString = queryItems
                .compactMap { item -> String? in
                    guard let value = item.value else { return nil }
                    return "\(item.name.uriEncoded)=\(value.uriEncoded)"
                }
                .joined(separator: "&")

            // Canonical request
            let canonicalURI = components.path  // e.g. "/bucket/object"
            let canonicalHeaders = "host:\(host)\n"
            let signedHeaders = "host"
            let payloadHash = "UNSIGNED-PAYLOAD"

            let canonicalRequest = [
                "GET",
                canonicalURI,
                canonicalQueryString,
                canonicalHeaders,
                signedHeaders,
                payloadHash
            ].joined(separator: "\n")

            // String-to-sign
            let stringToSign = [
                algorithm,
                amzDate,
                credentialScope,
                canonicalRequest.sha256Hex
            ].joined(separator: "\n")

            // Signing key and signature
            let signingKey = sigV4SigningKey(
                secretKey: config.secretKey,
                dateStamp: dateStamp,
                region: region,
                service: service
            )
            let signature = stringToSign.hmacSHA256(key: signingKey).hexString

            // Final query items (including signature)
            var finalQueryItems = queryItems
            finalQueryItems.append(URLQueryItem(name: "X-Amz-Signature", value: signature))
            components.percentEncodedQuery = finalQueryItems
                .compactMap { item -> String? in
                    guard let value = item.value else { return nil }
                    // Use percent encoding for query items
                    let encodedName = item.name.addingPercentEncoding(withAllowedCharacters: .urlQueryAllowed) ?? item.name
                    let encodedValue = value.addingPercentEncoding(withAllowedCharacters: .urlQueryAllowed) ?? value
                    return "\(encodedName)=\(encodedValue)"
                }
                .joined(separator: "&")

            guard let presignedURL = components.url else {
                return .failure(.presignFailed("Failed to construct URL"))
            }

            return .success(presignedURL.absoluteString)
        }
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App → S3 endpoint (PUT) | File data crosses network to S3-compatible storage |
| Pre-signed URL → Clipboard | URL with embedded signature crosses to system pasteboard |
| File data → Process memory | File content read into Data before upload |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Information Disclosure | uploadFile() Data(contentsOf:) | accept | File data is read into memory for upload. For large files (100MB+), this could be an issue, but v1 doesn't support streaming upload yet. Documented as known limitation. |
| T-02-01-02 | Information Disclosure | Pre-signed URL on clipboard | mitigate | URL contains X-Amz-Credential (access key ID, not secret). Signature proves authorization but doesn't leak secret key. Clipboard is user-controlled — standard macOS behavior. |
| T-02-01-03 | Tampering | Pre-signed URL signature | mitigate | SigV4 signature covers entire canonical request (HTTP method, URI, query params, headers). URL cannot be modified without invalidating signature. |
| T-02-01-04 | Repudiation | S3 upload auth | accept | x-amz-access-key header approach is consistent with Phase 1. SigV4 for URL generation only. |
</threat_model>
