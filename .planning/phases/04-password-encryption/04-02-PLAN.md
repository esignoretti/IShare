## Trust Boundaries

| Boundary | Description |
|----------|-------------|

| composeEmail() ↔ system mail | Email body sent to NSWorkspace — must NOT include password |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-05 | I | composeEmail() | mitigate | SHAR-11 enforced: grep-confirmed zero references to encryptionPassword in email body. Password note says "provided separately" |
| T-04-06 | T | Encryption toggle UI | accept | Password mismatch is shown via red text but does not prevent re-entry. User-friendly UX, low-risk |
| T-04-07 | S | encryptionPassword in memory | accept | Password lives in ShareItem for the share session duration (< 1 min). No persistence. Cleared when ShareItem deallocates |
