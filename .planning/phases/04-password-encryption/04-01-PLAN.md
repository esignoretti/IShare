- ShareItem encryption fields (encryptionPassword, isEncrypted)

  <action>
    Create `Sources/IShare/Services/EncryptionService.swift`:

    1. Define `EncryptionError` enum conforming to `Error, LocalizedError`:
       - `.encryptionFailed(String)` — wraps openssl errors
       - `.decryptionFailed(String)` — wraps openssl errors
       - `.passwordRequired` — when password is empty
       - `.fileNotFound(URL)` — source file doesn't exist

    2. Define `EncryptionService` struct with a static method:
       ```swift
       static func encryptFile(sourceURL: URL, password: String) async -> Result<URL, EncryptionError>
       ```
       Implementation:
       - Guard against empty password (return `.passwordRequired`)
       - Guard source file exists (return `.fileNotFound`)
       - Derive output URL by appending `.enc` to the sourceURL path
       - Use `Process` (same pattern as ditto in ShareService) to run:
         ```
         /usr/bin/openssl enc -aes-256-cbc -pbkdf2 -iter 100000
           -pass pass:<password> -in <sourcePath> -out <outputPath>
         ```
       - `withCheckedContinuation` pattern matching ShareService.compress()
       - On success: return `.success(outputURL)`
       - On failure: return `.failure(.encryptionFailed(...))`

    3. Add a static property:
       ```swift
       static let encryptedFileExtension = "enc"
       ```

    4. Add (optional but useful) static decrypt method for reference:
       ```swift
       static func decryptFile(sourceURL: URL, password: String, outputURL: URL) async -> Result<Void, EncryptionError>
       ```
       - `/usr/bin/openssl enc -d -aes-256-cbc -pbkdf2 -iter 100000 -pass pass:<password> -in <sourcePath> -out <outputPath>`
       - Not called in the app but useful for documentation/reference

    Follow project conventions: no external dependencies, macOS .v14, CommonCrypto not needed (using openssl CLI instead).

       Insert between `.compressing` and `.uploading` to maintain flow order. Keep it Equatable.

    **Part B — ShareService.swift changes:**

    1. At the top, ensure `EncryptionService` is importable (it's in the same module, no import needed).

    2. In `share(_:onUpdate:)` method, insert encryption step between compression and upload:

       ```
       After compression block, before upload block:

       if mutableItem.isEncrypted {
           mutableItem.state = .encrypting
           onUpdate(mutableItem)

           let encryptResult = await EncryptionService.encryptFile(
               sourceURL: mutableItem.fileURL,
               password: mutableItem.encryptionPassword
           )

           switch encryptResult {
           case .success(let encryptedURL):
               mutableItem.fileURL = encryptedURL
               mutableItem.objectKey = nil  // will be recomputed by uploadFile
           case .failure(let error):
               mutableItem.state = .failed(error.localizedDescription)
               onUpdate(mutableItem)
               return mutableItem
           }
       }
       ```

    3. Cleanup in `cleanupTempFiles()`:
       - The encrypted temp file is in the temp dir and should be cleaned up
       - Check: if item was encrypted AND the fileURL is in temp directory, remove it
       - Add after existing zip cleanup:

         ```swift
         // Clean up .enc temp files
         if !item.encryptionPassword.isEmpty {
             let tempDir = FileManager.default.temporaryDirectory
             if item.fileURL.path.hasPrefix(tempDir.path) {
                 try? FileManager.default.removeItem(at: item.fileURL)
             }
         }
         ```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | I | EncryptionService.encryptFile() | mitigate | Password passed via `-pass pass:` to openssl CLI — process arguments visible in `ps`. Acceptable for local macOS app (single-user). If multi-user, switch to pipe-based password passing via stdin. |
| T-04-02 | E | ShareService.cleanupTempFiles() | mitigate | Encrypted temp files deleted from temp directory after share completes |
| T-04-03 | S | ShareItem.encryptionPassword | mitigate | Password stored only in memory during the share session, never persisted to disk or included in email |
