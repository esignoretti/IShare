# Future Enhancements

- **Multi-bucket support:** Allow managing multiple S3 endpoints/buckets
- **Client-side encryption:** Encrypt files before upload with user-provided key
- **Upload progress:** Show progress bar in menu bar or notification
- **Drag-and-drop:** Allow dragging files onto menu bar icon instead of only Quick Actions
- **Link expiration preview:** Show remaining TTL for each shared file in the tray list
- **Notification on access:** Get notified when a shared file is downloaded (requires S3 event notifications)
- **Custom duration:** Allow user to type custom expiration time
